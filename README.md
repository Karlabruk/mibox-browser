# MiBox Browser 1.1

Navegador para Android TV (Mi Box 4K) com bloqueio de anúncios, rastreadores, domínios maliciosos e pop-ups.

## Novidades da 1.1
- Barra de ferramentas no topo: voltar, avançar, recarregar/parar, início, barra de endereço e menu
- Barra de progresso do carregamento
- Página inicial própria (sem propaganda), com favoritos e contador de bloqueios
- Favoritos, escolha do buscador (Brave Search, DuckDuckGo, Google) e tamanho do texto
- Teclado na tela abre ao clicar em campos de texto dos sites
- Chave de assinatura fixa: as próximas versões podem ser instaladas por cima

## Controle remoto
- Setas: movem o ponteiro. Para rolar a página: empurre o ponteiro até a borda de baixo da tela (rola para baixo) ou até a borda de cima (rola para cima)
- OK: clica (na barra de endereço, no site, nos botões)
- OK segurado (~1 segundo) ou botão Menu: abre o menu
- Voltar: volta uma página; na primeira página, fecha o app

## Como atualizar
Suba os arquivos deste ZIP no GitHub (Add file > Upload files), substituindo os antigos, e clique em Commit. O build roda sozinho (aba Actions) e o novo APK aparece em Releases.
